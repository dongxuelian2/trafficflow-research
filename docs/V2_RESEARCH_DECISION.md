日期：2026-10-16。配套：[数学推导](V2_MATHEMATICAL_DERIVATION.md)、[文献证据](V2_LITERATURE_REVIEW.md)、[架构与资源](V2_ARCHITECTURE_PROPOSAL.md)。本轮仅文档、静态数据审计和微型数学核验；没有训练、生成新 submission、调用 Kaggle 或覆盖旧报告。

## 1. 基准事实与分数空间

用户给出的当前正式最佳为 **0.83021**。本地 `reports/research/formal_scores.json` 最后核验的是 2026-10-14 的 **0.82940 / ref 57138874**，没有可核验的 .83021 对应 submission 记录。本轮把 .83021 当作用户提供的规划起点，把 .82940 当作可审计的历史对照，不改写旧成绩，也不为核验分数访问 Kaggle。正式四个分项的绝对值未知。

从 .83021 到 .90 / .95 的差距为 .06979 / .11979。若仅一项改善，所需分项增量为：

| 唯一改善任务 | 到 .90 | 到 .95 |
|---|---:|---:|
| State，权重 .35 | .199400 | .342257 |
| Queue，权重 .30 | .232633 | .399300 |
| Physics，权重 .15 | .465267 | .798600 |
| ODME，权重 .20 | .348950 | .598950 |

这些是差额除权重，不是可实现预测；若当前分项已较高，其余空间不足。举例，假设 State=.95、OD=.85，则即使 Queue=Physics=1，总分也只有 .9525；达到 .95 要求 Queue/Physics 几乎饱和。该假设不是对当前隐藏分项的估计。因此，.95 很可能需要多任务同时实质提升，不能靠某一方向 .005 State 开发增益外推。

## 3. K01 退化：能证明什么，不能证明什么

正式记录为：旧基准 .82940，OD-only Bayesian .76474，其余任务逐行相同，故

\[
\Delta S_O=(.76474-.82940)/.20=-.32330\quad(\text{舍入约 }\pm.00005).
\]

OD 中 dev 与 attr 权重合计 .30，即使两项从 1 全降为 0 也不足解释全部下降。因此

\[
.45\Delta S_{od}+.25\Delta S_{link}\le-.02330
\]

（相应考虑舍入），路径或 link 部分至少有净损失。这个推论不依赖猜测隐藏分项，也不能进一步说路径分单独下降多少。

公开 validation 行为诊断显示：Bayes 相对 Ridge 的 L2 变化平均 99.94% 位于计数零空间；总需求约为 Ridge 的 80.74%；相对弱先验的 L1 偏移约为 Ridge 的 1.56 倍（`EXPERIMENTS.md` K01/D05 记录）。这支持“先验相关结构把可观测残差传播到了错误零空间/总量”的解释，但不唯一证明其为全部原因。可能同时存在 prior 生成方向错配、噪声相关性错配、非负截断、复合评分与后验均值不匹配。

下一步若研究 OD，应固定正式 Ridge，对不同生成假设报告敏感性和风险区间；不能根据一次正式失败反向调一个新的 prior 参数，再用自己的模拟分证明成功。公开计数已拟合很好时，link 子项最多贡献总分的 .05，进一步拟合的剩余收益很有限。

## 4. 候选比较与优先级

| 候选 | 可能新增的信息/结构 | 最大风险 | 实施资源 | 决策 |
|---|---|---|---|---|
| A：未知边界 CTM + MHE | 库存守恒、延迟传播、边界后验、平滑/滤波统一 | 观测算子不匹配、短 link、边界不可识别 | 稀疏 CPU 首版，低 GPU 依赖 | **第一候选**，先闭合与可观测性门槛 |
| B：物理主模型 + 神经残差 | 学习有限闭合误差，保留输运约束 | residual 吸收一切、硬物理拖累 State | 小网络可控，子步反传可能很贵 | 与 C 合成第二候选，先无 NN 消融 |
| C：混合事件连续状态 | 容量变化、持续/恢复、相关前沿后验 | 未来事故无信号，事件稀少/选择偏差 | 低维情景可控，完整粒子法昂贵 | **第二候选的主体** |
| D：结构化概率 OD | 给出可识别量及先验敏感性 | 正式负证据、巨大零空间、错误生成分布 | CPU 够用，统计风险最高 | 不选为前二实现路线 |
| 全域 PINN / Neural ODE | 可微参数化/方程正则 | 激波、错设、资源和辨识问题 | 高不确定性 | 不优先 |
| DGAE / 更大 GAT | 不同传播先验 | 与已有 attention 重复 | 8GB 可能可行，需实测 | 对照而非主路线 |

第一候选是观测与动态是否相容的科学检验；第二候选是条件事件分布是否含新增预测信息的检验。两者都可能被快速否决，不能提前认定必然进入大规模训练。

## 5. 模型一：明确假设与最小实验

**模型**：观测偏差分层、低维未知边界、固定 FD 的 CTM–MHE；可选离线 smoother 与因果 filter。详见架构第 3 节。

**H1（可证伪）**：在公平输入/目标域下，公开观测含有现有树/图平滑未利用的方向性动态信息；加入正确的边界不确定性处理后能提高 State，且不会只降低自定义损失。

**H2（可证伪）**：容量事件只有在约束活跃、上游/下游观测能区分需求变化时才收缩后验；否则应保持宽区间。强制每次给出确定事故位置将产生过度自信。

最小方案（尚未执行）：

1. **结构预检**：I5_N 与 I210_W 两方向，先各选不超过 24 个两小时历史窗口，覆盖自由流/拥堵与观测稀疏情形。只使用训练角色可见数据。列出全部未解析边界，测试观测聚合与守恒残差，执行 profile likelihood。
2. **停止门槛**：无法合理保留瓶颈/匝道进行几何聚合，或无需改变状态即可用边界自由度吸收全部残差，停止 CTM 扩展。数值残差小不是通过依据。
3. **重构试验**：预登记 fit/cal/assessment 日期和三种 R 遮挡，至少 14 个 assessment 日；对冻结强树、现有图残差平滑、CTM 固定边界、CTM 未知边界四者做同域比较。先 12 步窗，仅 calibration 决定是否试 24/36 步；最多三种观测算子。
4. **指标**：完整官方 State 聚合；低速/跳变/恢复条件 RMSE；边界后验先验敏感性；公开 FD、时间密度增量代理，明确后两者不是官方 Physics。可用自建 CTM 做已知输入与未知输入配对消融，仅作失败诊断。
5. **晋级门槛（研究门槛，不是统计事实）**：主 State 宏分至少 +.002，配对日 block bootstrap 重算 pooled 宏分的 95% 区间下限 >0，两个方向均不出现超过 .001 的退化；结果不因合理边界先验变更而反号。未达门槛即不扩大网络。

若只改善代理 Physics 而 State 下降，不以加权总分猜测抵消，因为真实 Physics 增量不可见。若没有足够独立日期，报告功效不足，不把更密窗口当新样本。

## 6. 模型二：明确假设与最小实验

**模型**：低维半马尔可夫事故/容量/恢复模式 + 连续交通后验 + 可选保守通量残差；共享 noisy State decoder，Queue 用六步轨迹集合决策。详见架构第 4 节。

**H3（可证伪）**：相同合法历史下，事件持续时间/空间前沿后验比现有树概率提供更好的条件位置与规模信息，尤其是 T+30 onset；不是单靠 nonempty 或新阈值取得优势。

**H4（可证伪）**：小型保守残差能修正物理主模型的系统偏差，而不吸收真实事故/需求、不损害 State。若仅无约束残差有效，应否定物理部分的必要性。

最小方案（尚未执行）：

1. 选择已有 Queue 强参照和事件记录的 I5_N、I10_W，沿用严格 ≤T 的 13 时刻输入。预登记秋/冬 fit/cal/assessment，按 origin 去重；至少 30 个独立 onset 事件才报告初步方向性结论，事件不足时不扩大结论。
2. 首轮只拟合低维事件 hazard/持续/前沿，不训练大型网络。比较：当前树+原解码；相同树概率+新集合候选；事件模型+同原解码；事件模型+轨迹集合。这样分离信息收益与解码收益。
3. 物理闭合通过模型一门槛后，才加隐藏维 16–32 的小残差。消融固定 CTM、非保守等参数量残差、保守残差；固定训练样本、曝光次数、初始化种子、calibration 搜索预算。
4. 指标：condition 等权完整六步 IoU；onset T+30 位置/基数误差；ongoing 前沿误差；概率校准；同输入因果 State 子集与 noisy/latent 代理差异。禁止读取未来 eligibility 后再做 top-k/nonempty。
5. 研究晋级门槛：相对强参照 Queue proxy 至少 +.02，配对事件日期 bootstrap 区间下限 >0，两个方向与两个季节符号一致；State 配对非劣界 −.001。首次只做小预算，两次 fit seed 是优化稳定性检查，不是两倍独立事件。

这些门槛通过仍不证明官方 latent Queue 提升。需先在多种观测噪声与独立未来事故的压力反例中检查鲁棒性；自建模型无法检验真实选窗分布。最终正式验证应在后续用户授权阶段进行，本轮不提交。

## 7. 当前误差来源的可辨认程度

| 误差来源 | 已有证据强度 | 下一步区分方法 |
|---|---|---|
| 估计方差/有限标签 | 有：标签量控制改变结果；跨 seed 有变化 | 匹配标签、曝光、损失与参数量，不只匹配 epoch |
| 模型偏差/错误物理 | 有：密度约束损伤 State；自建 flux 与观测投影差异大 | 少量观测算子比较、held-out 创新白化、动态消融 |
| 观测不足/不可识别 | 强：OD 秩；自由流速度导数为零；未知边界混淆 | 灵敏度奇异值、nuisance 消元、profile likelihood |
| 分布失配 | 强负证据：Bayes 模拟正、正式显著负；跨家族迁移失败 | 先验压力测试、leave-family、季节分割；不声称已知隐藏分布 |
| Queue 未来事件不可预测 | 数学上可能，实证比例未知 | 历史匹配事件的条件熵/校准诊断，区分检测与提前预测 |

不能从一个总分把误差精确分摊为四种百分比，也不能断言主要瓶颈一定是 Queue 或 Physics；正式分项未知。研究优先级来自剩余结构机会、失败证据和可否决成本，而不是未经观测的分项猜测。

## 最终选择

优先实际实现 **未知边界、观测偏差分层的 CTM–MHE**；其次实现 **半马尔可夫事件驱动的保守残差状态空间模型**。OD 保留正式控制，先研究可识别量与先验敏感性。两条路线都有改变信息利用方式的可能性，但公开证据不足以保证 .90，更不足以保证 .95。最重要的下一步结果可以是明确否决一个错误物理假设，而不必是一个更复杂、代理分更高的模型。
